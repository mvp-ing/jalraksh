# Satellite Output Directory

This folder stores generated satellite imagery from the Earth Engine simulation.

## Structure
```
satellite_output/
├── {station_code}/
│   ├── original_raw/
│   │   ├── frame_000.png
│   │   └── ...
│   └── simulated_raw/
│       ├── frame_000.png
│       └── ...
```

## Notes
- Images are generated by the satellite agent using Google Earth Engine
- They are served via the backend API at `/api/satellite/images/{station_code}/{folder}/{filename}`
- Each station code has its own subfolder
